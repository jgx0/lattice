## Vault configuration

The source vault is configured in `publish.config.json`. The development server watches the vault and rebuilds when a note, attachment, or theme changes.

Obsidian themes are loaded from `.obsidian/themes`; enabled CSS snippets and `publish.css` are included in the generated site.
